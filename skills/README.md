# Skills

Ein Skill sagt der KI, wie sie eine bestimmte Arbeit machen soll: was sie vorher fragt, wie das Ergebnis aussieht, welcher Ton passt. Jeder Skill ist eine einzige Textdatei `SKILL.md`, oben Name und Beschreibung, darunter die Anweisungen in normaler Sprache.

| Skill | Wofür |
|---|---|
| [antwort-auf-beschwerde](antwort-auf-beschwerde/SKILL.md) | Eine ruhige, ehrliche Antwort auf eine Beschwerde, für Betrieb oder Verein |
| [bewerbung](bewerbung/SKILL.md) | Ein Bewerbungsschreiben, das zur Stelle passt und nach dir klingt |
| [brief-ans-amt](brief-ans-amt/SKILL.md) | Ein sachlicher Brief an eine Behörde in Österreich |
| [einkaufsliste](einkaufsliste/SKILL.md) | Aus einem Wochenplan eine Einkaufsliste, nach Abteilungen sortiert |
| [erklaeren-fuer-kinder](erklaeren-fuer-kinder/SKILL.md) | Etwas so erklären, dass ein Kind es versteht |
| [glueckwunsch](glueckwunsch/SKILL.md) | Ein Glückwunsch in eigenen Worten |
| [rechnung-pruefen](rechnung-pruefen/SKILL.md) | Eine Rechnung Zeile für Zeile prüfen, bevor du zahlst |
| [reise-planen](reise-planen/SKILL.md) | Eine kurze Reise planen, Tag für Tag, ohne Erfundenes |
| [termin-vorbereiten](termin-vorbereiten/SKILL.md) | Einen Termin vorbereiten: Ziel, Fragen, Unterlagen |
| [zusammenfassen](zusammenfassen/SKILL.md) | Einen langen Text in einer Minute erfassen |

## Verwenden

- **Im Programm:** unter „Skills“ sind diese Vorlagen schon dabei.
- **In der App:** im Platzl bei einem Skill auf „Skill verwenden“ tippen.
- **Anderswo:** Das Format ist dasselbe wie bei vielen anderen KI-Werkzeugen. Die Dateien lassen sich auch dort verwenden.

## Einen eigenen schreiben

Vorlage, Tipps und Grenzen stehen in **[Einen Skill schreiben](SKILL-SCHREIBEN.md)**. Zeig deinen Skill im [Platzl in der Kategorie Skills](https://forum.kiplatz.at/), probier ihn am Handy aus und verbessere ihn mit der Community. Gute Skills kommen mit dem Einverständnis ihrer Verfasser hierher.
