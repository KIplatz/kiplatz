# Building along at KIplatz

Great that you want to join in. We don't take contributions here on GitHub but on our own sites. Everyone sees them there, you get a reply there, and afterwards your name can appear on [Who builds](https://kiplatz.com/who-builds/).

| You want to … | Then go here |
|---|---|
| report a mistake, bring in an idea, suggest a source | [Workshop, project KIplatz/mitbauen](https://werkstatt.kiplatz.at/KIplatz/mitbauen?lang=en-US), with a template for every report |
| write, share or improve a skill | [Forum (Platzl), category Skills](https://forum.kiplatz.at/?tl=en) |
| ask a question or talk with others | [Forum (Platzl)](https://forum.kiplatz.at/?tl=en) |
| improve a guide | in the workshop with "Fork" and a change request, see [Wiki, Build along](https://kiplatz.com/wiki/build-along/) |
| report a security hole | confidentially, see [SECURITY.md](SECURITY.md) |

One account works for the forum, the workshop and the program: [create one for free](https://werkstatt.kiplatz.at/user/sign_up?lang=en-US), with an email address or Google. Most conversations are in German so far; you're welcome to write in English.

How we treat each other is set out in the [house rules](https://kiplatz.com/house-rules/). In short: stay friendly, welcome newcomers, stay on topic, stay honest and keep other people's data private.

## Auf Deutsch: Mitbauen bei KIplatz

Schön, dass du mitmachen willst. Beiträge nehmen wir nicht hier auf GitHub entgegen, sondern auf unseren eigenen Plätzen. Dort sehen sie alle, dort bekommst du eine Antwort, und dort steht dein Name danach auf [Wer mitbaut](https://kiplatz.at/wer-mitbaut/).

| Du willst … | Dann hier |
|---|---|
| einen Fehler melden, eine Idee einbringen, eine Quelle vorschlagen | [Werkstatt, Projekt KIplatz/mitbauen](https://werkstatt.kiplatz.at/KIplatz/mitbauen) mit Vorlagen für jede Meldung |
| einen Skill schreiben, teilen oder verbessern | [Platzl, Kategorie Skills](https://forum.kiplatz.at/) |
| eine Frage stellen oder dich austauschen | [Platzl](https://forum.kiplatz.at/) |
| eine Anleitung verbessern | in der Werkstatt mit „Fork“ und Änderungsvorschlag, siehe [Wiki, Mitbauen](https://kiplatz.at/wiki/mitbauen/) |
| eine Sicherheitslücke melden | vertraulich, siehe [SECURITY.md](SECURITY.md) |

Ein Konto gilt für Platzl, Werkstatt und Programm: [kostenlos anlegen](https://werkstatt.kiplatz.at/user/sign_up), mit E-Mail-Adresse oder Google.

Wie wir miteinander umgehen, steht in der [Platzordnung](https://kiplatz.at/hausordnung/). Kurz gesagt: freundlich bleiben, Neue willkommen heißen, beim Thema bleiben, ehrlich bleiben und fremde Daten privat lassen.
