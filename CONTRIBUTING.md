# Mitbauen bei KIplatz

Schön, dass du mitmachen willst. Beiträge nehmen wir nicht hier auf GitHub entgegen, sondern auf unseren eigenen Plätzen. Dort sehen sie alle, dort bekommst du eine Antwort, und dort steht dein Name danach auf [Wer mitbaut](https://kiplatz.at/wer-mitbaut/).

| Du willst … | Dann hier |
|---|---|
| einen Fehler melden, eine Idee einbringen, eine Quelle vorschlagen | [Werkstatt, Projekt KIplatz/mitbauen](https://werkstatt.kiplatz.at/KIplatz/mitbauen) mit Vorlagen für jede Meldung |
| einen Skill schreiben, teilen oder verbessern | [Platzl, Kategorie Skills](https://forum.kiplatz.at/) |
| eine Frage stellen oder dich austauschen | [Platzl](https://forum.kiplatz.at/) |
| eine Anleitung verbessern | in der Werkstatt mit „Fork“ und Änderungsvorschlag, siehe [Wiki, Mitbauen](https://kiplatz.at/wiki/mitbauen/) |
| eine Sicherheitslücke melden | vertraulich, siehe [SECURITY.md](SECURITY.md) |

Ein Konto gilt für Platzl, Werkstatt und Programm: [kostenlos anlegen](https://werkstatt.kiplatz.at/user/sign_up), mit E-Mail-Adresse oder Google.

Wie wir miteinander umgehen, steht in der [Platzordnung](https://kiplatz.at/hausordnung/). Kurz gesagt: freundlich bleiben, Neue willkommen heißen, beim Thema bleiben, ehrlich bleiben und fremde Daten privat lassen.
